# Documentation Overview

This folder contains more indepth documentation for how av-denoise and its algorithms work. It aims to help you
understand when and when not to make certain decisions along with how to get the best quality out of it.

- **[Choosing an algorithm](CHOOSING_AN_ALGORITHM.md)** - How to pick between NL4D, NLMeans-HQ and regular NLMeans.
- **[Tutorial for CLI](TUTORIAL-CLI.md)** - The tutorial for getting started with the CLI.
- **[Tutorial for VapourSynth](../av-denoise-vs/README.md)** - The tutorial for getting started with the VapourSynth plugin.
- **["Don't do this!"](DONT_DO_THIS.md)** - A list of common footguns and things to avoid along with why.
- **[Tuning guide for CLI](TUNING-CLI.md)** - How to tune each algorithm respectively for the CLI.
- **[Tuning guide for VapourSynth](TUNING-VS.md)** - How to tune each algorithm respectively for the VapourSynth plugin.
